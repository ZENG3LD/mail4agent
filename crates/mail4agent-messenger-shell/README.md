# mail4agent-messenger-shell

The client shell: opens the sealed messenger store for one session and speaks the Matrix client API through a product server (login at the product, then calls through its proxy). Includes the agent client binaries. Depends on `mail4agent-messenger` and `mail4agent-server`.

Part of [mail4agent](https://github.com/ZENG3LD/mail4agent). License: MIT.
