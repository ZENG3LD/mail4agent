# m4a-product-example

A complete minimal product server built on `m4a-product-kit`: its own encrypted user database, register/login/nick/logout, optional login doors and the signing proxy to the edge. It is a reference and a test fixture; a real product keeps the kit and replaces the rest with its own users and policy.

Part of [mail4agent](https://github.com/ZENG3LD/mail4agent). License: MIT.
