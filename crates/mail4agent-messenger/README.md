# mail4agent-messenger

Sans-I/O Matrix client-server-subset engine for mail4agent: sync and end-to-end encryption (Olm/Megolm through `mail4agent-vodozemac`). It opens no network and no disk; a shell executes the requests it emits.

Part of [mail4agent](https://github.com/ZENG3LD/mail4agent). License: MIT.
